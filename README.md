# Say the Capital

A voice game for kids: hear a country or a capital, answer out loud in English. One self-contained `index.html`, no build step.

## Flags and map
Flags (flag-icons) and the map outlines (world-atlas, Natural Earth) are written into `index.html` by a small script, so the game stays a single file:

```bash
cd tools && npm install && npm run assets
```
